# Retrieval Intelligence Engine (RIE)

## AI-Powered Document Intelligence Platform

Retrieval Intelligence Engine (RIE) is a Retrieval-Augmented Generation (RAG) system designed to transform unstructured PDF documents into an intelligent knowledge base.

Users can upload multiple PDFs, perform semantic search, generate summaries, and interact with documents through natural language conversations powered by Large Language Models.

---

## Core Features

- Multi-PDF Knowledge Base Creation
- Conversational Question Answering
- Semantic Retrieval
- Context-Aware Responses
- Document Summarization
- Source Attribution
- Persistent Vector Storage
- Downloadable Chat History
